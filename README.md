# 🍜 今餐食乜

Tinder 式揀餐廳 web app。定位 → 揀距離 → 掃卡片。
左掃 = 下一間，右掃 = 睇詳情（評分、距離、熱門評論、地址、電話、營業時間、一鍵導航）。

只得 **一個 `index.html`**，冇 npm、冇 build、冇後端。雙擊就開到。

---

## 而家點用

雙擊 `index.html`（或者拖入瀏覽器）。三個入口：

- 🚇 **揀港鐵站**（推薦）— 全港 98 個站，唔使任何權限，喺屋企都 plan 到聽日去邊食
- 📍 **用我而家嘅位置** — GPS 定位（⚠️ 見下面「GPS 唔 work？」）
- 🧪 **示範模式試玩** — 假設你喺中環

## ⚠️ GPS 唔 work？唔係 bug

**瀏覽器規定：只有 `https://`（或者 localhost）先俾網頁攞 GPS。**
你雙擊開個檔案，網址係 `file://`，唔算安全來源，所以 GPS **一定失敗** —— 任何網頁都係咁，唔關個 app 事。

三個解決方法：

1. **用「揀港鐵站」** — 即刻用得，而且喺香港其實仲實際（你 plan 緊去邊食嗰陣，人未必喺嗰度）
2. **放上網** — GitHub Pages / Netlify 都係 https，放咗上去 GPS 就正常（見下面「放上網」）
3. 本機起個 server：`python3 -m http.server` 然後開 `http://localhost:8000`

個 app 會自動偵測到你係 `file://`，直接話你知兼且俾個掣你跳去揀港鐵站。

## 🚇 港鐵站數據

98 個站，同官方香港重鐵站數目一致。座標由 OpenStreetMap 擷取，線路歸屬人手核對過
（雙向檢查：冇孤兒站、冇幽靈站）。實測旺角站座標 400 米內搵到翠華、銀龍茶餐廳、
大家樂 —— 準確。

- **搜尋** — 打「灣」即刻列出長沙灣、荃灣、灣仔、銅鑼灣…
- **線路篩選** — 十條線用返官方顏色
- **轉車站** — 會顯示晒所屬線路（例如金鐘 = 荃灣綫・港島綫・東鐵綫・南港島綫）
- **最近揀過** — 記住你最近 5 個站，置頂顯示，唔使次次搵

數據離線嵌喺 `index.html` 入面（3.5KB），唔使 call 任何 API。

⚠️ 而家用緊 **示範數據**（55 間香港餐廳，評分同評論都係假嘅，只係示範個界面）。
要真實數據，跟下面步驟插 Google API key。

## 換成真實 Google 數據（10 分鐘）

### 1. 開 Google Cloud 專案

1. 去 https://console.cloud.google.com/
2. 上面「選擇專案」→ **新增專案** → 名叫 `eat-what` 之類
3. 左邊選單 → **帳單 Billing** → 綁一張信用卡
   - 唔綁就用唔到 Places API
   - ⚠️ 免費額度點計，睇下面「[實際要幾錢](#實際要幾錢2026-年最新)」— 一定要睇，2025 年 3 月改過制

### 2. 開啟 Places API (New)

左邊選單 → **API 和服務** → **程式庫** → 搵 **Places API (New)** → 撳「啟用」

⚠️ 一定要揀 **Places API (New)**，唔好揀舊嗰個 `Places API`（本 app 用新版格式）。

### 3. 攞 API key

1. **API 和服務** → **憑證** → **建立憑證** → **API 金鑰**
2. 複製條 key（`AIza...` 開頭）
3. 撳個 key 入去改設定 — **呢步好重要，唔做人哋會偷用你張卡**：
   - **應用程式限制** → 揀「**網站**」
     - 加你會放個網頁嘅網域，例如 `https://你個名.github.io/*`
     - 本機測試再加 `http://localhost/*`
   - **API 限制** → 揀「**限制金鑰**」→ 只剔 **Places API (New)**
4. 儲存

### 4. 插入 key

用文字編輯器開 `index.html`，搵到最頂嘅設定區（大約第 400 行）：

```js
const CONFIG = {
  GOOGLE_API_KEY: '',        // ← 貼喺呢度，例如 'AIzaSyD...'
  DATA_SOURCE: 'auto',       // auto = 有 key 就用 Google，冇就用示範數據
  MAX_RESULTS: 50,
};
```

貼入去，儲存，重新整理個網頁。底下嗰個「🧪 示範數據」標籤消失 = 接通咗真實數據。

想強制睇返示範數據就改 `DATA_SOURCE: 'mock'`。

### 5. 設一個用量上限（一定要做）

Google Cloud → **帳單** → **預算和快訊** → 建立預算，設 HK$50，超過就 email 你。
咁樣就算出事都唔會收到天價帳單。

## 實際要幾錢（2026 年最新）

**⚠️ 網上好多教學仲寫「每月 US$200 免費額度」— 呢個已經冇咗。**
Google 喺 2025 年 3 月改成**每個 SKU 各自有免費上限**，而且唔會夾埋用：

| 級別 | 每月免費 |
|---|---|
| Essentials | 10,000 次 |
| Pro | 5,000 次 |
| **Enterprise** | **1,000 次** |

本 app 要星級同評論，所以兩樣都跌落最貴嗰檔：

| 用途 | SKU | 每月免費 | 超額價 |
|---|---|---|---|
| 搜尋餐廳（要評分／相片／營業狀態） | Enterprise | 1,000 次 | US$35 / 1,000 |
| 攞評論（`reviews` 欄位） | Enterprise + Atmosphere | 1,000 次 | US$40 / 1,000 |

### 唔慳嘅話會點

一日午晚兩餐、每餐掃 20 間 = 一個月大約 1,200 次評論 call → 已經爆額度。
掃得密啲（每餐 50 間）可以去到 3,000 次/月 → 超額 2,000 次 → **約 US$80/月**。

### 個 app 幫你做咗嘅嘢

1. **只攞最面嗰張卡嘅評論** — 背後兩張唔會預先攞
2. **評論快取 30 日** — 同一間餐廳一世人只 call 一次（`REVIEW_CACHE_DAYS`）
3. **搜尋結果快取 6 個鐘** — 同一日喺同一區搵嘢食唔會重複 call（`SEARCH_CACHE_MIN`）

住喺同一區嘅話，頭一兩個星期 call 完附近嗰批餐廳，之後幾乎係零消耗。

### 想再慳，改一個掣

`index.html` 頂嘅 `CONFIG` 入面：

```js
PREVIEW_REVIEWS: false,   // 卡片唔顯示評論，右掃睇詳情先至攞
```

改咗之後卡片變成全幅相片（都幾靚），評論用量大概少 5–10 倍 —— 因為你只會揀啱先右掃。
**如果你係自己一個用，呢個設定基本上永遠唔會收到錢。**

## 放上網（免費）

因為只係一個 HTML 檔，最易嘅方法：

**GitHub Pages**
1. 開一個 GitHub repo，upload `index.html`
2. repo → Settings → Pages → Source 揀 `main` branch → Save
3. 幾分鐘後就有 `https://你個名.github.io/repo名/`
4. 記得返去 Google Cloud 將呢條網址加入 key 嘅網站限制

**Netlify Drop**（更快，唔使 git）
去 https://app.netlify.com/drop，直接拖個資料夾入去。

放咗上網之後，喺 iPhone Safari 開個網址 → 分享 → **加入主畫面**，就好似個真 app 咁。

放上網仲有個好處：**GPS 定位會即刻正常**（因為 GitHub Pages 同 Netlify 都係 https）。

## 三種玩法（改 `CONFIG` 就轉到）

`index.html` 頂嘅 `CONFIG` 有兩個掣，夾出三種唔同性格嘅 app：

### 🅰️ 全 Google（預設，最靚）

```js
DATA_SOURCE: 'auto',        // 有 key 就用 Google
SWIPE_RIGHT_ACTION: 'sheet',
```
星級 Top 50 排名、相片、營業狀態、卡片直接見到 Top 3 評論。
**要 key + 信用卡**，用量睇上面「[實際要幾錢](#實際要幾錢2026-年最新)」。

### 🅱️ Google 排名 + 跳出去睇（慳錢，我推薦）

```js
DATA_SOURCE: 'auto',
PREVIEW_REVIEWS: false,
SWIPE_RIGHT_ACTION: 'gmaps',   // 或者 'openrice'
```
保留星級 Top 50 排名同相片（一次搜尋攤分幾十間，超抵），
但**完全唔 call 最貴嗰個評論 API** —— 右掃直接跳 Google Maps／OpenRice，
喺嗰邊睇到全部評論同相簿，仲多過 API 俾你嗰 5 則。

實際用量：一日兩餐 + 6 個鐘快取 ≈ 每月幾十次搜尋 call，**穩穩陣陣喺 1,000 免費額度內**。

### 🅾️ 完全免費，一蚊都唔使畀

```js
DATA_SOURCE: 'osm',
SWIPE_RIGHT_ACTION: 'openrice',   // 或者 'gmaps'
```
用 OpenStreetMap（免費、唔使 key、唔使信用卡、唔使 Google Cloud 戶口），
右掃跳去 OpenRice 睇評分同食評。

**代價要認清**：OSM 冇評分，所以**冇咗「Top 50 by stars」排名**，改成按距離由近到遠。
卡片亦冇相片，得個 emoji。變成「幫你抽一間」多過「幫你揀最好」。

## 🍚 OpenRice 直達（意外收穫）

原本以為 OpenRice 完全接唔到，點知喺 OSM 數據入面發現：**唔少香港餐廳帶住
`ref:openrice` 標籤**，即係 OpenRice 嘅店舖編號。有編號就砌得返直達連結：

```
https://www.openrice.com/zh/hongkong/r-x-r1618   → 九記牛腩
https://www.openrice.com/zh/hongkong/r-x-r1966   → 陸羽茶室
```

實測過真係開到正確嗰間餐廳個頁。冇編號嗰啲就跳去 OpenRice 搜尋結果，一樣搵到。

設 `SWIPE_RIGHT_ACTION: 'openrice'` 就會啟用。卡片上會有個橙色
**🍚 開飯喇有得睇** 標籤話你知邊幾間係直達。

⚠️ 實測中環 1 公里內，342 間食肆入面得 **45 間（13%）**有 OpenRice 編號。
其餘要靠搜尋，準確度睇個名夠唔夠特別（「麥當勞」就會搵到成堆）。

## 有冇得唔用 Google？（2026 年 7 月調查結果）

短答：**香港市場冇得換。** 逐個試過：

| 方案 | 星級 | 文字評論 | 免費額度 | 香港覆蓋 |
|---|---|---|---|---|
| **Google Places** | ✅ | ✅ | 1,000/月 | 🟢 最好 |
| Foursquare | 💰 Premium | ⚠️ 只有 tips | ❌ Premium 零免費 | 🟡 中等 |
| Yelp | ✅ | ✅ | ❌ 2026 起冇免費 | 🔴 亞洲基本死咗 |
| TripAdvisor | ✅ | ✅ 5 則 | 🟢 5,000/月 | 🔴 偏旅客區 |
| Overture / OSM | ❌ | ❌ | 🟢 完全免費 | 🟢 位置齊全 |
| OpenRice | — | — | ❌ 冇公開 API | — |

**OpenRice** — 冇公開開發者 API。佢只同銀行做私有 API 對接（DBS、恒生嗰啲 Cash Dollars
整合），係 B2B 白牌合作，唔對外開放。前端 CORS 亦封死，爬蟲違反服務條款兼有防護。
市面上有第三方賣「OpenRice API」，實際係爬蟲代理服務，法律灰色地帶，唔建議個 app 起喺上面。

**但係**：雖然攞唔到佢啲數據，**跳過去佢個頁面係完全冇問題嘅**（同你自己撳個連結一樣）。
所以本 app 用 OSM 嘅 `ref:openrice` 標籤砌直達連結 —— 詳情睇上面
「[OpenRice 直達](#-openrice-直達意外收穫)」。

**Foursquare** — 評分屬 Premium endpoint，**冇免費額度**，第一次 call 就開始收錢
（US$18.75/1,000）。而且 2026 年 6 月起免費額度由 10,000 劈到 500 次 Pro call。
最要命係佢只有 tips（短貼士），冇 Google 嗰種完整評論。

**Yelp** — 2026 年已經全面取消免費方案，US$7.99–14.99/1,000，得 30 日試用。
更大問題係佢喺亞洲基本上冇人用，香港數據等於零。

**TripAdvisor** — 唯一免費額度大過 Google（5,000/月，有 5 則評論）。但佢係**旅遊平台**：
中環嘅米芝蓮同酒店餐廳有，深水埗嘅茶記、大牌檔、街坊小店基本上冇。
你個 app 嘅價值就係揾樓下嗰啲，所以唔啱。另外佢強制要顯示 TripAdvisor logo，
評論唔准改動或者重新排序。

**Overture Maps / OpenStreetMap** — 完全免費開源，香港嘅餐廳位置數據意外地齊全。
但佢**根本冇評分冇評論**（只有名、菜系、地址、營業時間）。你個 app 核心係
「Top 50 by stars」，冇星就冇得排。除非將來改成「隨機推介」模式，否則用唔著。

### 結論

用 Google，但要慳住用 —— 睇返上面「[實際要幾錢](#實際要幾錢2026-年最新)」嗰段，
快取同 `PREVIEW_REVIEWS` 兩招已經可以令你長期唔使畀錢。
